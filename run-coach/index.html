How do I get a key?
  1. Sign in to Garmin Connect on the web.
  2. Open the Personal API Key page and choose Create Key.
  3. Accept the terms and pick an expiry (30 days to 1 year).
  4. Copy the key right away. Garmin only shows it once.

More in the Personal API FAQ.

🔒 Your key goes only to the Run Coach server on this computer. The server swaps it for a 24-hour Garmin access token, keeps both in memory (never on disk) and only reads data. Disconnecting or stopping the server forgets them.
